# 0011. استفاده از HeroUI برای کامپوننت‌ها

- **وضعیت:** پذیرفته
- **تاریخ:** 2026-11-06

## مسئله

صاحب محصول خواست ساختار رابط کاربری بر پایه HeroUI باشد.

## تصمیم

- `@heroui/react` و `@heroui/styles` دقیقاً روی نسخه 3.2.7 قفل شده‌اند.
- دکمه، کارت، فرم، منوی انتخاب، پیام خطا و بقیه کامپوننت‌ها از HeroUI می‌آیند و نسخه دستی ساخته نمی‌شود.
- رنگ‌ها در `src/app/globals.css` با بازنویسی متغیرهای HeroUI تنظیم می‌شوند: `--accent` کهربایی است و `--link` رنگ لینک‌ها.
- `I18nProvider` با `fa-IR` دور کل برنامه است تا منوها و میان‌برهای صفحه‌کلید راست‌به‌چپ باشند.
- تم با `data-theme` روی `<html>` تعیین می‌شود، که HeroUI هم همان را می‌خواند.

## گزینه‌های ردشده

- **ادامه با کلاس‌های دستی Tailwind:** برای فرم‌ها و منوها باید دسترس‌پذیری و رفتار صفحه‌کلید را خودمان می‌ساختیم.
- **HeroUI v2:** نسخه قبلی است و پروژه جدید دلیلی برای شروع با آن ندارد.

## پیامدها

- HeroUI v3 با v2 فرق زیادی دارد. API را از `node_modules/@heroui/react/dist` بخوانید، نه از حافظه.
- در Server Component از نام‌های جدا مثل `CardRoot` و `CardHeader` استفاده کنید. شکل `Card.Header` فقط در Client Component قابل اعتماد است.
- برای لینکی که شکل دکمه دارد، `buttonVariants` از `@heroui/styles` را روی `next/link` بگذارید.
- واریانت `secondary` دکمه متن را با رنگ `--accent` می‌نویسد که در تم روشن خوانا نیست. به جایش `outline` یا `ghost` را به کار ببرید.
