# 0003. ماندن روی Prisma 7.10.1 به جای 8 RC

- **وضعیت:** پذیرفته
- **تاریخ:** 2026-11-06

## مسئله

در زمان ساخت پروژه، برچسب `latest` پکیج `prisma` روی npm به نسخه پیش‌انتشار `8.0.0-rc.30` اشاره می‌کرد، در حالی که `latest` پکیج `@prisma/client` نسخه `7.10.1` بود. نصب ساده این دو پکیج، نسخه‌های ناسازگار می‌داد.

## تصمیم

هر سه پکیج `prisma`، `@prisma/client` و `@prisma/adapter-pg` دقیقاً روی `7.10.1` قفل شده‌اند.

## گزینه‌های ردشده

- **رفتن همه به 8 RC:** نسخه پایدار نیست و برای شروع پروژه ریسک بی‌دلیل دارد.

## پیامدها

Prisma پیام به‌روزرسانی به نسخه 8 نشان می‌دهد که فعلاً باید نادیده گرفته شود. پس از انتشار نسخه پایدار 8، این تصمیم باید بازبینی شود. هر سه پکیج باید با هم ارتقا پیدا کنند.
