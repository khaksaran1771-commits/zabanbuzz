# دفتر تصمیم‌ها (Decision Log)

هر تصمیم مهم یک فایل کوتاه دارد که می‌گوید چه چیزی، چرا، و به جای چه گزینه‌هایی انتخاب شده است. برای تصمیم جدید، از `template.md` کپی بگیرید و یک ردیف به جدول زیر اضافه کنید.
