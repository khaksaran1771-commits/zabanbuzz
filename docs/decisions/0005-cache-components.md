# 0005. روشن ماندن Cache Components

- **وضعیت:** موقت
- **تاریخ:** 2026-11-06

## مسئله

قالب `create-next-app` گزینه‌های `cacheComponents` و `partialPrefetching` را به‌طور پیش‌فرض روشن کرده بود. این انتخاب آگاهانه ما نبود، ولی روی نوشتن هر کامپوننتی که داده می‌خواند اثر دارد.

## تصمیم

فعلاً پیش‌فرض قالب حفظ می‌شود. کامپوننتی که هنگام درخواست از پایگاه داده می‌خواند، `await connection()` را صدا می‌زند و داخل `Suspense` قرار می‌گیرد.

## گزینه‌های ردشده

- **خاموش کردن این گزینه‌ها:** کد ساده‌تر می‌شود، ولی پیش‌فرض جدید فریم‌ورک را کنار می‌گذارد، و هنوز دلیل مشخصی برای این کار نداریم.

## پیامدها

صفحه‌ها یک پوسته ثابت سریع دارند و داده پویا بعد از آن می‌رسد. اگر این الگو هنگام ساخت فیچرها دست‌وپاگیر شد، این تصمیم باید بازبینی شود.
