# 0002. Next.js، Postgres و خروجی standalone در داکر

- **وضعیت:** پذیرفته
- **تاریخ:** 2026-11-06

## مسئله

نیاز اولیه پروژه این بود: فرانت با Next.js، دسترسی به داده با Prisma، پایگاه داده Postgres، و بالا آمدن با داکر. باید مشخص می‌شد ایمیج چطور ساخته شود.

## تصمیم

- Next.js با App Router، TypeScript و Tailwind
- PostgreSQL 17 و Node 26 روی ایمیج‌های alpine
- Dockerfile چندمرحله‌ای با `output: "standalone"`، که در نهایت فقط سرور لازم را اجرا می‌کند و با کاربر غیر root بالا می‌آید
- پورت Postgres فقط روی `127.0.0.1` باز است

## گزینه‌های ردشده

- **کپی کردن کل `node_modules` در ایمیج نهایی:** ایمیج را بی‌دلیل بزرگ می‌کند.
- **باز کردن پورت Postgres روی همه شبکه‌ها:** برای توسعه لازم نیست و پایگاه داده را در معرض شبکه قرار می‌دهد.

## پیامدها

ایمیج نهایی Prisma CLI ندارد، برای همین migration جدا اجرا می‌شود (تصمیم 0004). نکته‌ی وابستگی بیلد به Google Fonts با تصمیم 0010 برطرف شد.
