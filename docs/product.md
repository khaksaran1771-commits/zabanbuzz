# محصول

چیزهایی که هنوز تصمیم‌گیری نشده‌اند زیر «سؤال‌های باز» می‌مانند و نباید حدس زده شوند.

## Zabanbuzz چیست؟

سکویی برای داوطلبان کنکور ایران، با تمرکز بر سؤال‌های زبان، که آزمون‌ها و تدریس‌ها در آن قرار می‌گیرد. این فقط خلاصه است و جزئیات کامل تسک‌به‌تسک از صاحب محصول می‌رسد.

متن لندینگ (مباحث و روش کار) و سؤال نمونه‌ی آن پیش‌نویس هستند و هنوز تأیید نشده‌اند.

## برای چه کسانی است؟

| نقش | کار |
| --- | --- |
| دانش‌آموز | شرکت در آزمون‌ها و دیدن تدریس‌ها |
| مدرس | قرار دادن آزمون و تدریس |
| ادمین | مدیریت کاربران و نقش‌ها |

جزئیات کار هر نقش هنوز باید تأیید شود.

## چه چیزی ساخته شده؟

- ثبت‌نام و ورود با ایمیل یا شماره موبایل و رمز عبور
- پنل جدا برای هر نقش و تغییر نقش توسط ادمین
- ساختار ورود با کد یک‌بارمصرف که فعلاً خاموش است (تصمیم 0008)

## سؤال‌های باز

- [ ] کدام رشته‌ها، پایه‌ها و درس‌ها پوشش داده می‌شوند؟
- [ ] آزمون چه شکلی است: تستی، زمان‌دار، با نمره منفی؟ کارنامه و رتبه‌بندی دارد؟
- [ ] تدریس چیست: ویدیو، کلاس زنده یا جزوه؟ ویدیوها کجا میزبانی می‌شوند؟
- [ ] محتوا رایگان است یا پولی؟ اگر پولی است، با کدام درگاه پرداخت؟
- [ ] هر مدرسی می‌تواند محتوا منتشر کند یا ادمین باید تأیید کند؟
- [ ] کدام سرویس پیامک و ایمیل برای کد یک‌بارمصرف استفاده می‌شود؟
- [ ] محصول کجا دیپلوی می‌شود؟
